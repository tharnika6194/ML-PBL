# PrepAI – AI-Powered Interview Preparation System

## Project Overview

PrepAI is an AI-powered interview preparation platform designed to
help students practice technical and HR interviews, evaluate their
responses, receive feedback, and monitor their preparation progress.

## Key Features

- AI Question Generation
- AI Interview Simulator
- Technical Interview Practice
- HR / STAR Interview Practice
- Answer Evaluation
- Performance Analytics
- Interview History
- Preparation Roadmap
- Coding Workspace
- Personalized Performance Tracking

## Dashboard

The dashboard provides an overview of the user's interview preparation,
including preparation readiness, technical performance, communication
score, HR/STAR score, strongest skills, weakest skills, interview
sessions, and preparation streak.

![PrepAI Dashboard](screenshots/dashboard.png)

## System Architecture

User → Login / Dashboard → Interview Selection → Question Generator
→ Answer Evaluation → Score & Feedback → Performance Tracking
